 # 🛍️ ShopWave - E-Commerce Website Enhancement

Welcome to the ShopWave project! This directory contains my E-Commerce Website developed during my internship at ShadowFox.

## 📋 Overview

ShopWave is a responsive and interactive e-commerce website designed to enhance the user experience through modern shopping features. The project demonstrates front-end development skills and practical implementation of an online shopping platform.

---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure and page layout
- **CSS3** – Responsive design and styling
- **JavaScript (ES6+)** – Dynamic functionality and interactivity
- **Bootstrap** – Modern UI components and responsiveness
- **Local Storage API** – Cart data management

---

## 📁 Folder Structure

```text
E-Commerce Website/
│
├── index.html             # Main homepage
├── products.html          # Product listing page

├── contact.html           # Contact page

├── style.css              # Main stylesheet

```
